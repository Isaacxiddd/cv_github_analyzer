# Privacy Policy

**Last updated:** 2025

## Data Handling

### CV Content
- **Never sent to any server** — all PDF parsing happens locally in your browser using pdf.js
- No CV data is uploaded, stored, or transmitted

### GitHub API
- Only **public** GitHub profile and repository data is fetched
- No authentication token is stored in v0.1 (anonymous API with 60 req/h limit)
- Data is used solely to generate the cross-check report within your browser

### Extension
- **No analytics, no tracking, no telemetry**
- No data is collected, logged, or shared with third parties
- Chrome storage is used only to cache GitHub API responses within your browser session

### Backend (v1.0+)
- When the optional backend is released, a separate privacy policy will apply
- You will be notified and asked for explicit consent before any data leaves your browser

## Updates

This policy may be updated as the project evolves. Changes will be reflected in this file and tagged in release notes.
